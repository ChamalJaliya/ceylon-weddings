# Lottie assets

Monochrome outline animations used by `@ceylonweddings/ui` `Icon` when a Lucide
name is mapped in `registry.ts`.

| File | Lucide names | Source |
|------|--------------|--------|
| `heart.json` | Heart, Flower2 | [Unicorn Icons — Heart](https://unicornicons.com/icons/heart) |
| `store.json` | Store, Shirt, UserRound | [Unicorn Icons — Shopping bag](https://unicornicons.com/icons/shopping-bag) |
| `check.json` | Check, Stamp | [Unicorn Icons — Tick](https://unicornicons.com/icons/tick) |
| `arrow-right.json` | ArrowRight | [Unicorn Icons — Arrow right](https://unicornicons.com/icons/arrow-right) |
| `search.json` | Search | [Unicorn Icons — Search](https://unicornicons.com/icons/search) |
| `star.json` | Star, Sparkles, Gem, MoonStar | [Unicorn Icons — Star](https://unicornicons.com/icons/star) |
| `home.json` | Building2, Building, Hotel, Home | [Unicorn Icons — Home](https://unicornicons.com/icons/home) |
| `image.json` | Camera, Image | [Unicorn Icons — Image](https://unicornicons.com/icons/image) |
| `cake.json` | Cake, UtensilsCrossed | [Unicorn Icons — Cake/Coffee](https://unicornicons.com/icons/cake) |
| `music.json` | Music | [Unicorn Icons — Music](https://unicornicons.com/icons/music) |
| `pin.json` | MapPin | [Unicorn Icons — Pin](https://unicornicons.com/icons/pin) |
| `calendar.json` | ClipboardList, Calendar | [Unicorn Icons — Calendar](https://unicornicons.com/icons/calendar) |
| `truck.json` | Car, Bus, Truck | [Unicorn Icons — Truck/Cycle](https://unicornicons.com/icons/truck) |
| `message.json` | Mail, MessageCircle | [Unicorn Icons — Message](https://unicornicons.com/icons/message) |
| `pencil.json` | Pencil, Scissors | [Unicorn Icons — Pencil](https://unicornicons.com/icons/pencil) |

License: Unicorn Icons free for personal and commercial use (no attribution required).
Assets are vendored under `animations/` so runtime does not depend on a CDN.
